# СОКРАТ — ИИ-наставник по математике для школьников

Мини-приложение и чат-бот для мессенджера **MAX**. Команда **Aksel**, лицей «Квант», г. Грозный.
Хакатон «Идея фикс», направление «Портал в будущее: встройте искусственный интеллект в школьную жизнь».

## Идея

Школьники всё чаще перепоручают домашние задания ИИ-чатам и перестают думать сами.
СОКРАТ использует ИИ наоборот: он **никогда не даёт готовый ответ**, а ведёт ученика
наводящими вопросами (сократический метод). Принцип последовательно применён ко всем частям:

| Функция | Как работает |
|---|---|
| **Пространство темы** | Ученик выбирает тему, ИИ готовит конспект, вопросы для самопроверки и первую задачу |
| **Сократический диалог** | ИИ задаёт по одному наводящему вопросу, не исправляет ошибки за ученика |
| **Лестница подсказок** | 4 ступени: наводящий вопрос → нужное правило → разбор похожей задачи → полное решение |
| **Автопроверка** | Определяет тип ошибки и место, где её искать, но не исправляет и не называет ответ |
| **Тест по личным ошибкам** | 5 вопросов, собранных из ошибок именно этого ученика |
| **Индекс самостоятельности** | 0–100: насколько ученик решает сам. Задача без подсказок с первой попытки = 100, каждая подсказка и лишняя проверка снижают вклад |

## Технологии

- Python 3.12, FastAPI, SQLite
- YandexGPT (Yandex AI Studio, Foundation Models API)
- MAX Bot API (`platform-api2.max.ru`) и MAX Bridge для мини-приложения
- Интерфейс: HTML/CSS/JS, KaTeX для формул

## Запуск через Docker

1. Скопируйте файл настроек и заполните его:

```bash
cp .env.example .env
```

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | Токен бота MAX (business.max.ru → Чат-боты → ⋮ → Настройки) |
| `YANDEX_API_KEY` | API-ключ сервисного аккаунта Yandex Cloud с ролью `ai.languageModels.user` |
| `YANDEX_FOLDER_ID` | ID каталога Yandex Cloud (`b1g...`) |
| `PUBLIC_URL` | Публичный HTTPS-адрес сервера (нужен для режима webhook) |
| `BOT_MODE` | `polling` (по умолчанию) или `webhook` |

Без `YANDEX_*` приложение работает в демо-режиме с ответами-заглушками.

2. Соберите образ и запустите контейнер:

```bash
docker build -t sokrat .
docker run -d --name sokrat -p 8000:8000 --env-file .env -v sokrat-data:/data sokrat
```

Пример запуска с переменными прямо в командной строке:

```bash
docker run -d -p 8000:8000 -e BOT_TOKEN=<токен> -e YANDEX_API_KEY=<ключ> -e YANDEX_FOLDER_ID=<каталог> -v sokrat-data:/data sokrat
```

3. Проверка: `http://localhost:8000/health` → `{"ok": true, ...}`.

4. Чтобы мини-приложение открывалось в MAX, адрес сервера должен быть доступен по **HTTPS**.
   Укажите его в настройках бота: business.max.ru → Чат-боты → ⋮ → Настройки → ссылка на мини-приложение.

Развёртывание на сервере с HTTPS (Docker Compose + Caddy) описано в [DEPLOY.md](DEPLOY.md).

## Запуск без Docker (для разработки)

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

С `DEV_MODE=1` в `.env` мини-приложение открывается в обычном браузере (`http://localhost:8000`)
под тестовым пользователем. На сервере, доступном из интернета, `DEV_MODE` должен быть `0`.

## Структура

```
app/
  main.py      — веб-сервер, API мини-приложения, вебхук бота
  bot.py       — чат-бот MAX: приветствие, кнопка «Открыть», ответы в чате
  tutor.py     — педагогическая логика и промпты (диалог, подсказки, проверка, тест, индекс)
  llm.py       — клиент YandexGPT
  max_api.py   — клиент MAX Bot API
  auth.py      — проверка подписи initData мини-приложения
  db.py        — схема и доступ к SQLite
webapp/        — интерфейс мини-приложения
certs/         — сертификат Минцифры (нужен для API MAX)
```

## Безопасность

- Пользователь мини-приложения определяется по подписанным данным MAX (`initData`, HMAC-SHA256 с токеном бота).
- Токены и ключи хранятся только в переменных окружения, файл `.env` не попадает в репозиторий.
- Храним только имя из MAX, класс и учебную статистику — без телефонов и других персональных данных.
